Sou desenvolvedor Full Stack com experiência no desenvolvimento de sistemas web, APIs, integrações, automações e soluções para ambientes corporativos e do setor público.

## 📂 Projetos

### 📌 SISA
Projeto desenvolvido de forma particular, voltado à integração e automação de processos para órgãos públicos. O SISA foi desenvolvido como uma solução própria para atender necessidades específicas de ambientes públicos, trabalhando com integração de sistemas, dados e processos existentes.
- **Tecnologias:** PostgreSQL, Docker, Java, REST APIs, Linux.
- **Principais desafios:** Integração com sistemas existentes, comunicação entre aplicações, manipulação de dados, automação de processos, diagnóstico de problemas em ambientes reais, integração com o ecossistema e-SUS.

### 📌 Ekoa Conecta
Sistema desenvolvido para conectar e centralizar informações e processos, oferecendo uma plataforma web para gestão e comunicação.
- **Tecnologias:** PHP, JavaScript, HTML, CSS, MySQL.
- **Características:** Aplicação web, gestão de informações, backend e frontend, banco de dados, automação de processos, interface responsiva.

### 📌 MindPDV
Sistema desenvolvido para gestão de operações de ponto de venda, com foco em organização e automação de processos comerciais.
- **Tecnologias:** PHP, JavaScript, MySQL, HTML, CSS.
- **Características:** Sistema de PDV, gestão de operações, regras de negócio, persistência de dados, interface web, automação.

### 📌 Soluções para o Setor Público
Além dos projetos próprios, também participei do desenvolvimento de sistemas sob demanda para a Prefeitura de Santa Luzia e outras necessidades relacionadas ao setor público.

#### Gestão de Funcionários Terceirizados
Sistema desenvolvido para auxiliar na gestão e acompanhamento de funcionários terceirizados vinculados aos serviços públicos.
- **Funcionalidades:** Cadastro de funcionários, gestão de informações, controle de terceirizados, organização de dados, acompanhamento administrativo, relatórios, consultas e automação de processos.

*O desenvolvimento desses sistemas proporcionou experiência prática com regras de negócio específicas, processos administrativos e necessidades reais de usuários do setor público.*
